## [三维光纤微镊实现十万倍力输出突破](https://www.stdaily.com/web/gdxw/2026-06/19/content_534836.html) ⭐️ 9.0/10

## [SMPTE 将其标准免费开放](https://www.smpte.org/blog/smpte-makes-its-standards-freely-accessible-openingstandards-library-to-the-global-media-technology-community) ⭐️ 8.0/10

## [IETF 提出 HTTP QUERY 方法：带请求体且安全幂等](https://httpwg.org/http-extensions/draft-ietf-httpbis-safe-method-w-body.html) ⭐️ 8.0/10

IETF HTTP 工作组发布了一份新草案，定义了 HTTP QUERY 方法，它允许在请求体（body）中发送查询参数，同时保持 GET 方法的安全和幂等特性。该草案于 2025 年 5 月 27 日发布，有效期至 2026 年 12 月。 这解决了长期以来 POST 查询无法安全缓存或重试的局限，从而支持更健壮和高效的 API 交互。若成为标准，它可简化 RESTful API 设计，并通过缓存中间件提升性能。 QUERY 方法包含一个新的 'Accept-Query' 响应头，让服务器声明支持的查询格式媒体类型。该草案仍在讨论中，最终定稿前可能会有变化。

telegram · zaihuapd · Jun 20, 06:28

**背景**: HTTP 方法分为安全（只读，不影响资源）和幂等（多次相同请求结果与一次相同）两类。GET 既安全又幂等，但其查询字符串有长度限制。POST 既不安全也不幂等，因为它通常创建或修改资源，导致缓存和自动重试存在风险。
