## [Mozilla 宣布淘汰 asm.js，WebAssembly 的前身](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html) ⭐️ 8.0/10

Mozilla 宣布淘汰 asm.js，这是一种严格的 JavaScript 子集，曾使网页应用接近原生性能，并为 WebAssembly 铺平了道路。 这标志着 asm.js 时代的终结。asm.js 曾证明 Figma 等高性能应用可以在浏览器中运行，其淘汰巩固了 WebAssembly 作为此类任务标准的地位。 此次淘汰是在 WebAssembly 广泛采用之后进行的，WebAssembly 相比基于 JavaScript 的 asm.js 具有更小的二进制大小和更快的解析速度。浏览器将继续在过渡期内支持 asm.js。

hackernews · eqrion · May 20, 12:01 · [社区讨论](https://news.ycombinator.com/item?id=48206340)

**背景**: asm.js 由 Mozilla 于 2013 年引入，通过使用浏览器 JavaScript 引擎可以高度优化的 JavaScript 子集，实现了在浏览器中以接近原生速度运行 C/C++ 代码。它后来被 WebAssembly 取代，WebAssembly 是一种可移植的二进制格式，于 2019 年成为 W3C 标准，现在所有主流浏览器都支持。
