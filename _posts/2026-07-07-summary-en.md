## [Tencent Releases Hy3, 295B MoE Model under Apache 2.0](https://simonwillison.net/2026/Jul/6/hy3/#atom-everything) ⭐️ 8.0/10

Tencent has released Hy3, a 295B-parameter Mixture-of-Experts (MoE) model with 21B active parameters and 3.8B MTP layer parameters, available under the Apache 2.0 license. The model outperforms similar-size models and rivals open-source models with 2-5x more parameters. This release demonstrates a new high-performing open-source LLM from China, competing with much larger models while being freely available. It could accelerate open-source AI development and offers free access on OpenRouter until July 21st, 2026. The full-precision model is 598GB on Hugging Face, with an FP8 quantized version at 300GB, and supports a context length of 256K tokens. Hy3 uses a Mixture-of-Experts architecture, so only a subset of experts (21B parameters) are activated per inference, reducing computational cost.

rss · Simon Willison · Jul 6, 23:57

**Background**: Mixture-of-Experts (MoE) is a neural network design where multiple specialized sub-networks (experts) are trained, and a gating mechanism selects only a few experts per input token. This allows models to have a large total parameter count while keeping active parameters small, improving efficiency. Active parameters refer to the subset of parameters actually used during inference. Tencent is one of China's largest technology companies, and Hy3 is their latest open-source language model.

## [Falcon 9 Reentry Creates Lithium Pollution Plume in Upper Atmosphere](https://t.me/zaihuapd/42387) ⭐️ 8.0/10

A new Nature sub-journal study has directly detected a lithium plume in the upper atmosphere at 96 km altitude, linked to the reentry of a SpaceX Falcon 9 rocket stage, marking the first direct measurement of metal pollution from rocket debris. This discovery highlights a novel form of atmospheric pollution from the growing space industry, with potential implications for the ozone layer and climate. Using high-precision lidar in northern Germany, scientists observed a tenfold increase in lithium concentration about 20 hours after the Falcon 9 upper stage reentered over Europe.

## [Claude Cowork Sandbox Escape Vulnerability Detailed](https://cyberpress.org/claude-cowork-flaw/) ⭐️ 8.0/10

A sandbox escape vulnerability in Anthropic's Claude Cowork feature for Windows was disclosed, allowing an attacker with prior local code execution to escape the Ubuntu VM and exfiltrate sensitive data like /etc/shadow. This vulnerability demonstrates that even isolated sandboxes can be bypassed when combined with local code execution, highlighting the importance of defending against initial compromise vectors. It also raises questions about Anthropic's risk classification, as they deemed it a non-issue despite the exfiltration potential. The exploit chain leverages DLL sideloading on claude.exe and two unvalidated parameters (isResume and allowedDomains) in the spawn interface to break out of the bubblewrap sandbox using nsenter. The issue was reported in March 2026 but was dismissed by Anthropic due to the prerequisite of existing local code execution.

telegram · zaihuapd · Jul 6, 14:53

**Background**: DLL sideloading is a technique where a malicious DLL is placed in a location searched by a legitimate executable, tricking it into loading the attacker's code. nsenter is a Linux command that allows running a program in the namespace of another process, commonly used to escape container sandboxes. bubblewrap is a lightweight sandboxing tool used by Flatpak and other container systems to restrict application access. The Claude Cowork feature runs code in an isolated Ubuntu VM, but the vulnerability chains these techniques to break out.
