On July 23, 2026, Science magazine published an exclusive investigation revealing that a 6-year-old girl died in March 2025 after receiving experimental base editing gene therapy at Xinhua Hospital affiliated with Shanghai Jiao Tong University. The trial bypassed regulatory oversight and was never publicly disclosed. This incident highlights serious breaches of ethical and safety standards in gene therapy research, potentially impacting global gene editing regulations and public trust. It also raises questions about oversight of clinical trials in China and the responsibility of top research institutions. Clinical trials require regulatory approval and public registration to ensure ethical conduct and safety monitoring.

## [Decker Revives HyperCard for Modern Interactive Documents](https://beyondloom.com/decker/) ⭐️ 8.0/10

Decker is a new multimedia platform that enables the creation of interactive documents with sound, images, hypertext, and scripted behavior, drawing strong influence from Apple's classic HyperCard. It is available as a free, cross-platform application for Windows, macOS, and Linux. Decker revives the accessible, card-based authoring model of HyperCard for a modern audience, potentially enabling non-programmers to easily create rich interactive experiences. Its release sparks discussion about the past and future of low-code tools and the democratization of software creation. Decker features a 1-bit graphic style and its own scripting language, inspired by HyperTalk, to control behavior. It is available for free on itch.io and can run as a standalone application or in a browser via a plugin.

hackernews · tosh · Jul 26, 18:23 · [Discussion](https://news.ycombinator.com/item?id=49060856)

**Background**: HyperCard was a revolutionary software application released by Apple in 1987 that combined a flat-file database with a graphical, user-modifiable interface and a built-in programming language called HyperTalk. It allowed users to create interactive "stacks" of cards for tasks ranging from simple databases to games, and it was famously easy to use, even for children. HyperCard was discontinued in 2004, but its influence persists in modern tools like Twine and LiveCode. Decker builds on this legacy by providing a similar authoring environment updated for current operating systems.

## [EU Proposes Browser-Level Privacy to Kill Cookie Banners](https://killthecookiebanner.eu/) ⭐️ 8.0/10

The EU Commission has proposed a new regulation allowing users to set their privacy preferences directly in their browser, which would automatically signal websites to eliminate cookie banners. This would replace the current system where users must manually consent on each site. This could dramatically improve user experience by removing annoying cookie banners while strengthening privacy, though it raises concerns about whether browser-set preferences truly constitute informed consent. It may also impact the ad-tech industry that relies on cookie-based tracking. The proposal builds on existing technologies like Global Privacy Control (GPC), which allows users to send an opt-out signal via HTTP headers. However, critics argue that browser-level defaults may not provide the granularity some users want for different sites.

They are widely criticized for being intrusive and often designed to nudge users into accepting tracking. The Global Privacy Control (GPC) is a previous attempt to standardize a browser signal for opting out of data sharing.

A privacy vulnerability in Anthropic's Claude AI shared link feature has caused numerous user conversations to be indexed by search engines like Google, exposing sensitive data such as API keys, crypto wallets, and social security numbers. This breach undermines user trust in Claude's privacy protections and could lead to identity theft or financial loss. Anthropic has not yet fixed the issue, unlike OpenAI which patched a similar ChatGPT vulnerability within days. The vulnerability stems from missing noindex meta tags on shared links, allowing search engines to crawl and index them. Google has since blocked the pages, but Brave and Bing still index them as of the report.

telegram · zaihuapd · Jul 26, 11:16

**Background**: When users share a Claude conversation via the 'share' feature, a public link is generated. Without a noindex directive, search engine bots can discover and index these pages, making them searchable. This is a common web privacy issue; platform owners must explicitly block indexing to protect user-generated content intended for private sharing.
