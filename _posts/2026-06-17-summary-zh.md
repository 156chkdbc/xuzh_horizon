## [停止在浏览器会话中使用 JWT](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

一篇广受分享的 gist 文章认为，不应将 JSON Web Token（JWT）用于基于浏览器的用户会话，引发了对 JWT 安全性和恰当使用场景的新一轮争论。 这一点很重要，因为 JWT 是现代网络认证的基石，但在浏览器会话中误用 JWT 可能引入严重的安全漏洞，促使开发者重新思考无状态与有状态会话管理的选择。 批评主要针对 JWT 难以在服务端轻松撤销、存储在浏览器存储中时容易遭受 XSS 和 CSRF 攻击，以及默认无状态总是有益的错误假设；文章还指出 JWT 适用于服务间通信。

hackernews · dzonga · Jun 16, 16:49 · [社区讨论](https://news.ycombinator.com/item?id=48558147)

**背景**: JSON Web Token（JWT）是一个开放标准（RFC 7519），用于在双方之间以 JSON 对象形式传输声明，常用于认证和授权。在浏览器会话中，JWT 常被存储在 localStorage 或 cookie 中，但与存储在服务端的传统会话 ID 不同，如果不维护黑名单就无法撤销。这引发了关于无状态与有状态会话管理的安全讨论。

据报道，苹果正计划进行一项变更，使‘隐藏我的邮箱’功能实际上变得无用，因为服务将无法再向这些别名发送电子邮件，除非预先注册。 这削弱了数以百万计用户依赖的 iCloud+ 关键隐私功能，可能推动用户转向 SimpleLogin 或 Fastmail 等替代邮件别名服务。 据报道，此变更要求向‘隐藏我的邮箱’别名发送邮件的服务必须预先注册，从而破坏诸如发货通知和发票等事务性邮件；用户每小时可预先生成最多 30 个别名。

hackernews · SXX · Jun 16, 18:37 · [社区讨论](https://news.ycombinator.com/item?id=48559935)

**背景**: ‘隐藏我的邮箱’是 iCloud+ 的一项功能，可生成唯一、随机的电子邮件地址，并转发到用户的个人收件箱，允许他们在不透露真实邮箱的情况下注册服务。它依赖苹果转发传入邮件，但即将到来的变更将限制哪些发件人可以在未经事先批准的情况下到达别名。

## [Android 17 发布：强制大屏适配，集成 AI 功能](https://android-developers.googleblog.com/2026/06/Android-17.html) ⭐️ 8.0/10

Android 17 已正式推送至支持的 Pixel 设备并开放源代码。该版本强制要求应用适配大屏，移除了开发者锁定大屏方向与尺寸的选项，并要求应用原生支持自由窗口和多种设备形态。 此次更新对全体 Android 开发者提出了重大更改，大屏适配不再可选，通过 AppFunctions 实现的 AI 集成允许 Google Gemini 等 AI 助手进行更深层次的系统级交互，同时新的临时权限和本地网络权限增强了用户隐私保护。 Android 17 引入了 AppFunctions 作为平台 API 及对应的 Jetpack 库，允许应用将功能作为“工具”暴露给设备上的 Model Context Protocol (MCP)。系统会根据设备总内存强制执行严格的内存上限，并优化了垃圾回收和消息队列性能。此外，Google 宣布 Android 开发全面转向 Jetpack Compose，传统 View 组件进入维护模式。

telegram · zaihuapd · Jun 17, 01:02

**背景**: Android 是 Google 的移动操作系统，每个主要版本都会引入新功能和需求。大屏适配是指确保应用在平板、折叠屏等大屏设备上良好运行。AppFunctions 是一个新 API，允许 Google Gemini 等 AI 助手直接调用应用内功能，类似于模型上下文协议 (MCP)。Jetpack Compose 是一个现代 UI 工具包，使用声明式编程构建原生 Android 界面。

## [GitHub Copilot 改为按 token 计费，GPT-5.5 乘数 57 倍](https://t.me/zaihuapd/42003) ⭐️ 8.0/10

GitHub 宣布自 2026 年 6 月 1 日起，GitHub Copilot 将转为按 token 使用量计费。在新模式下，用户将获得每月 AI Credits 额度，而仍使用传统年度计划的老用户，每次 GPT-5.5 请求的计费乘数高达 57 倍。 这一重大定价模式变化将影响数百万依赖 GitHub Copilot 的开发者和组织。GPT-5.5 的高乘数反映了先进 AI 模型成本上升，可能增加重度用户的费用，迫使他们重新评估预算。 计费转换适用于所有付费 Copilot 计划，每月 AI Credits 将取代之前的请求配额。传统年度计划用户可在计划到期前继续使用旧模式，但新订阅和续订将采用基于 token 的系统。

telegram · zaihuapd · Jun 17, 03:16

**背景**: 以往 GitHub Copilot 采用固定月费或基于请求的计费方式，支持 GPT-4、Claude 等模型。新的基于 token 的定价与行业趋势一致，因为 AI 模型变得更加资源密集。GitHub AI Credits 是一种计算单位，根据模型复杂度和使用类型消耗。GPT-5.5 的乘数意味着每次请求消耗的基础信用额度是简单模型的 57 倍。
